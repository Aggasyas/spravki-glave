## Как открыть на мобильном

Приватный репозиторий. Варианты доступа:

1. **GitHub Mobile** — открыть репо → файл `index.html` → «View raw» → HTML отрендерится в браузере.
2. **Прямая ссылка** (после логина в GitHub в браузере телефона):  
   `https://raw.githubusercontent.com/Aggasyas/spravki-glave/main/<папка>/index.html`
3. **Клонирование**: `git clone git@github.com:Aggasyas/spravki-glave.git`
